**근거 품질 규칙 (2026-08-23 제안서 v1 오류 2건의 교훈 — 준수 강제)**:
- **"코드 확인" 3단계**: 심볼/enum **전체 나열** → 사용처 검색 → 파일:줄 인용. 단편 grep 몇 건으로 "존재 안 함" 판정 금지.
- **외부 주장은 출처 등급 필수**: ★★★(공식 원문)/★★(검증 2차)/★(커뮤니티 — 경향 서술만, 정량 금지)와 확인일을 함께 기록. 등급·확인일 없는 주장은 기입 금지.

- **판정 규율 상속**: E/U/P/X/D/S(경쟁 비교는 S만 "지원"), 주장 수위 사다리(COMPETITIVE_ANALYSIS §1.6), 미감사 영역 경쟁표 기입 금지.
- **산출물 상한**: 분석 1회당 신규 파일은 제안서 1개까지. 나머지는 기존 문서·원장 행 갱신.
