## 이번 회차 개선 실행 증분 (§6-7) — QAUTO-01 3차

**known-invalid 컨트롤 preflight(CA-18·21)**: 두 드라이버가 실측 전에 컨트롤을 돌려 게이트 발화를 증명하고, 발화 확인 자체를 qauto 기록(CONTROL_OK/CONTROL_FAIL)으로 남기며, 컨트롤 실패 시 실측을 거부.
- CA-18: 프레임(25ms)보다 짧은 무음 픽스처 → 0검출 → degeneracy 강제 FAIL 발화 확인(어제 막은 거짓-PASS 경로 그 자체를 정기 발화 검증).
- CA-21: 손상 픽스처 → rc≠0·스위트 실실행 표식(0-tests 가짜그린 함정 배제)·PASS 부재 3조건으로 게이트 거부 확인.
- **검증 실측(전행)**: CA-18 CONTROL OK → 실측 FAIL(12/12·40.1%/31.9% — 기준 동일)·CA-21 CONTROL OK → 실측 PASS(recall 0.875·precision 1.000 — 기준 동일). 거부 분기는 셸 조건 단위 검증 3케이스(rc=0·마커 부재·정상 로그) 확인. 스크래치 잔존 0.
- 유의: 재빌드 발생 — 디스크 압박으로 빌드 캐시가 정리된 것으로 추정(−15Gi의 상당분 설명. 루프 임시는 358MB뿐).
