[MovieCut 다음 개발 방향 자문 요청 — 제품 상태 요약 포함]

**제품**: MovieCut — Mac+iOS 네이티브 동영상 편집기. 완전 오프라인·무계정·무구독(일회성 구매 예정). 타깃: 1인 크리에이터(아이폰/미러리스 촬영, CapCut은 출력·프라이버시가 불안하고 Final Cut Pro는 과도하다고 느끼는 층). 검증 인프라가 강점: 다단계 빌드 게이트, Core 유닛테스트 약 1,480개, 프리뷰↔출력 픽셀 파리티 검증(MAD ≤2.0), 5개 대표 작업(토킹헤드/비트 몽타주/합성/5분 마스터/카드뉴스) 실길이 E2E 클린 풀 패스, 베타 시나리오 루프 4/4 PASS.

**경쟁 위치 (실측 문서 기반)**:

1) **CapCut 대비**
- 이기는 축(실측 확정): 완전 오프라인(네트워크 차단망에서 임포트→프리뷰→출력 완주·소켓 캡처 0), 무료·무로그인·무제한(CapCut은 로그인 필수·캡션 프로젝트당 10분 제한·Pro $19.99/mo), 스코프 4종(히스토그램·웨이브폼·벡터스코프·RGB 파레이드 — CapCut 없음), ProRes/10-bit 출력, 멀티밴드 EQ DSP+자동 덕킹(CapCut 데스크톱은 EQ 부재·덕킹 수동), 온디바이스 STT 캡션 무제한
- 지는 축: 콘텐츠 볼륨(필터/이펙트/전환/템플릿 — CapCut 수백 종 vs 선별 수십 종), 컴파운드 클립, 보컬 분리·보이스 체인저(보류), 프롬프트 기반 AI Auto-Edit 통합, 상용 음악/SFX 라이브러리
- 성능 대외 비교: A/B 벤치마크 하니스 완성(30분 소스 RTF 0.299·A/V 싱크 오차 0.000s 등 자체 수치 양호)이나 경쟁사 출력물 확보 전이라 블라인드 비교 실측 전 — 대외 성능 주장은 보류 중

2) **Final Cut Pro 대비**
- 명시적 비목표: 멀티캠·자동 동기화·Auditions·서드파티 플러그인·FCPXML 상호운용·서라운드·stem export. "FCP급" 주장은 출력 정확성·색·음향 일관성·미디어 생존성으로 범위 제한
- 이기는 축: 가격($299.99 일회성 vs 저희 일회성 미정), macOS 14 지원(FCP는 15.6+ 요구), 오프라인, Mac+iOS 동시 파리티, roles·타임라인 인덱스 등 장편 관리 세트 일부

3) **Palmier Pro 대비** (2026-06 출시 오픈소스 Mac AI 네이티브 편집기 — MCP 서버 내장, AI 에이전트가 타임라인에서 직접 클립 생성·트림·재정렬, 로컬 AI 생성 지원)
- 'AI 에이전트가 편집하는' 축은 선점당함. 저희는 관련 프로바이더 코드가 미배선 상태
- 저희 차별화: iOS 동시 파리티, 검증 게이트 체계, 대표 작업 E2E

**사용성 현재 상태**:
- 웹 버전: 없음·명시적 비목표(오프라인 원칙)
- iOS: 핵심 경로(임포트→편집→출력) 시뮬레이터 E2E로 잠김(83테스트), 첫실행 온보딩 3단계+샘플 템플릿+신규 사용자 첫 출력 ≤10분 메트릭, 현지화 en/ko 100%, 접근성(VoiceOver 등) 완료, 자동저장·크래시 복구 UX 완료
- 남은 리스크: ① 아직 배포 전(TestFlight 진입이 개발자 계정/Team ID 확보 대기 — 사용자 액션 블록) ② 실기기 검증 1/3(터치 체감·발열·오디오 라우팅 미검증, 사진 임포트가 실기기에서 실패할 수 있는 결함 후보 1건) ③ iOS 고급 기능 UI 표면 부족(EQ·덕킹·노이즈 감소 조작 없음, 출력 .mov 중심) ④ CapCut식 템플릿 '고르면 끝' 온보딩과의 격차(전략상 경쟁 불응 원칙)

**현재 대기/진행 중**:
- 베타 우선 전략 확정(기능 확장 의도적 동결). Team ID 수신 시 아카이브→TestFlight 배포까지 자동화 준비 완료
- 보조 트랙: 측정 하니스 provenance 강화(자율 루프가 매일 1증분씩 진행)
- 승인 대기 기능: 대사 검색 기반 편집, 제안형 오토스타일, 템플릿·효과 확장, AI 음성 등

**질문**: 이 상태에서 다음 개발 방향(3~6개월)의 우선순위를 잡아달라. 구체적으로:
(a) 베타 출시 전 사용성 마무리의 최소 범위 — 무엇을 꼭 닫고 나가야 하고 무엇을 베타 후로 미뤄도 되는가
(b) 베타 피드백 루프 설계 — 어떤 지표·코호트로 '쉬운지'를 판정해야 하는가 (첫 출력 ≤10분 외에)
(c) Palmier식 'AI 에이전트 편집' 축 — 지금 대응할 것인가 무시할 것인가. 한다면 오프라인 원칙 안에서 어떤 형태가 가능한가
(d) CapCut 격차 중 전략적으로 닫아야 할 것 vs 영구 경쟁 불응이 맞는 것
(e) 성능 대외 실측(경쟁사 출력 블라인드 비교) 타이밍 — 베타 전/후 어느 쪽이 맞나

답변은 우선순위 순서로, 각 항목에 이유와 판단 기준(측정 가능한 형태)을 붙여달라.
