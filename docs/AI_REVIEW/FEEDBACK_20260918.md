## 3. 귀속 판정 — 10% 미만을 "외부"로 확정하면 안 됨

10%는 negative evidence threshold로는 좋으나 확정하면 너무 강함(CoreSimulator·APFS·swap·미관측 경로 때문). 정량 계약 권장:

```
disk_drop = prev_available - cur_available
direct_growth = Σ positive_delta(repo, .build, tmp)
correlated_growth = Σ positive_delta(DerivedData, CoreSimulator)
direct_ratio = direct_growth / disk_drop
observed_ratio = (direct+correlated) / disk_drop
```

**4단계 판정**: MOVIECUT_ATTRIBUTABLE(direct ≥60%, 또는 direct ≥30% && direct+correlated ≥70%) / MOVIECUT_CONTRIBUTING(10~60%) / **EXTERNAL_DOMINANT**(MovieCut <10% **이면서** 별도 external 경로 증가가 drop의 상당 부분 설명) / **UNATTRIBUTED**(MovieCut <10%인데 다른 관측 경로에서도 원인 미발견). 예: drop 4.65GiB에 MovieCut observed +0.28GiB=6%뿐이면 EXTERNAL_DOMINANT가 아니라 UNATTRIBUTED가 맞음 — 동시에 /private/var/vm +3.6GiB가 잡히면 그제야 EXTERNAL_DOMINANT 근거 충분.
