# AI 영상 제작 구현 세션 시작용 지시문

아래 내용을 새 구현 세션에 전달한다. 이 문서는 다른 세션을 자동으로 생성하거나 실행하지 않는다.

> **[2026-10-05 저녁 갱신]** AI-03 구현 후 첫 E2E(16:15)에서 오디오 램프 중첩 예외가 발견되어 실패했다(task-511.log). **다음 세션은 AI-04 이후 신규 기능이 아니라 [AI_VIDEO_CREATION_DEFECT_REPAIR_PLAN_20261005.md](AI_VIDEO_CREATION_DEFECT_REPAIR_PLAN_20261005.md)의 결함 수리부터 수행한다** — 순서 M3a(fixture 접근) → M1(램프 중첩) → M2·M4 → M3b → M5 → M6. 램프 중첩 원인은 이미 특정되어 있다(전역 덕킹 블록이 클립 fade와 중복 검사 없이 같은 파라미터에 램프 추가 + 이미지 클립의 음성 분류 오류). 상태표(§14)도 정정 완료.

MovieCut에 Palmier처럼 AI가 사진·영상·음원을 받아 편집 가능한 영상을 만드는 기능을 구현해줘.

먼저 `docs/AI_VIDEO_CREATION_IMPLEMENTATION_PLAN_20261005.md`를 읽고, 현재 코드와 차이를 확인한 뒤 그 계획에 따라 단계적으로 구현해줘. 문서의 새 타입·파일명은 제안이니 동등한 기존 기능이 있으면 재사용해줘.

최종 목표는 다음 요청을 기존 MovieCut 타임라인에서 수행하는 것이야:

> “여행 사진 10장으로 세로 30초 영상을 만들어줘. 사진에 천천히 움직임을 주고, 밝은 음악을 깔고, 전환에 효과음을 넣고, 마지막에 문구를 넣어줘.”

그 뒤 “세 번째 사진을 2초 늘리고 전체 길이는 유지해줘”, “마지막 효과음을 빼줘”, “내레이션 동안 음악을 줄여줘”처럼 수정하고, 저장·재열기·내보내기까지 이어져야 해. 다음 단계에서는 이미지·영상·음악·효과음 생성 모델을 연결해줘.

구현 원칙:

1. Mac 우선, 기존 Core/렌더/오디오/ExportEngine 재사용. MCP는 기존 결정대로 보류.
2. 현재 앱의 `AIEditingProvider → AssistantIntent` 경로와 P3 `EditingActionDSL → EditingActionApplier` 경로를 조사해 통합. 기존 기능을 삭제하지 말고 매핑해줘.
3. 순차 드래프트 검증, 안정적인 신규 객체 참조, revision 비교 커밋, 단일 undo/redo를 먼저 구현해줘. 현재 적용기가 원본 상태만 검사하는 한계를 그대로 두고 액션 수만 늘리지 마.
4. 편집 배치와 외부 생성 작업은 분리해줘. 생성 결과는 검증된 로컬 자산으로 준비한 뒤 같은 편집 명령으로 삽입해줘.
5. 외부 AI는 opt-in·BYOK 기본안, 키는 Keychain, Core는 네트워크 구현과 분리. 공급자 모델·가격·기능은 구현 시 공식 문서를 확인해 결정해줘. 키가 없어도 mock·로컬 경로 개발과 검증은 진행하고 실제 API 검증만 미완료로 표시해줘.
6. 기존 완전 오프라인 정책과 외부 AI의 차이를 관련 문서·설정에서 명확하게 다뤄줘. 모델이 설정되지 않았는데 외부 호출로 자동 폴백하지 마.
7. 현재 git 상태·다른 작업의 변경·디스크 START_GATE를 확인해줘. iOS Simulator 설치·재설치·테스트는 기존 정책대로 하지 말고, 허용된 generic device 빌드만 사용해줘.
8. 각 패키지의 행동 테스트와 실제 미리보기·출력 검증을 남겨줘. 코드 존재·mock 성공·과거 수치를 실제 사용자 기능 완료로 보고하지 마.

첫 작업은 계획의 AI-00 → AI-01 → AI-02/03 최소 수직 증분으로 진행해줘. **사진 3장과 음악 1개로 15초 타임라인 생성 → undo/redo → 실제 export**를 먼저 확보하고, 이후 자유 자연어 플래너·믹싱·생성 통합으로 확장해줘.

작업이 이어지도록 상세 계획 §14의 상태표에 완료한 작업, 변경 파일, 실행한 테스트, 증거 경로, 미검증 항목과 다음 작업을 기록해줘. 큰 기존 운영 문서에 완료 사실을 추측해서 덮어쓰지 마.

## 이 계획을 작성한 세션의 수행 범위

- 현재 코드·정책·기존 P3 문서를 읽고 상세 구현 계획과 이 지시문을 작성했다.
- 제품 코드는 변경하지 않았다.
- 빌드·테스트·앱 실행·유료 생성 호출은 수행하지 않았다.
- 다른 채팅 생성·메시지 전송·자동화 설정은 수행하지 않았다.
