## 코드 경로 근거 (조사)

- VFR→CFR: 합성 `frameDuration`/`minFrameDuration` (`ExportEngine.swift:597,995-1010`)
- 10비트·색: `RenderColorConfiguration` — v1 계약 "8비트 SDR Rec.709 단일 고정(32BGRA)" (`RenderColorConfiguration.swift:45-50`) — 최초 판정과 달리 near-black의 원인은 이 변환 경로가 아니라 **범용 aspect-fit 부재(BUG-06)**로 판명(ec5c9e3 — 3개 렌더 경로 전부 코너 1:1 렌더). 10→8비트 변환 자체는 콘텐츠 영역 Δ0.9로 무결
- 회전: `preferredTransform` 전달 (재생 `PlaybackEngine.swift`·출력 `ExportEngine.swift`·커스텀 컴포지터 `CustomVideoCompositor.swift`) — BUG-07 해결(2026-08-25)로 세 경로 모두 회전→핏 순서로 결합 적용, 방향 실측 검증(유닛 4종 + 매트릭스 E2E)
- 혼합 레이트: `AudioGraphSourceAdapter` 리샘플 (`:43-44`) + 60분 드리프트 실측
