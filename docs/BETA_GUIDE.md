# MovieCut 베타 테스터 가이드

> 대상: v1 Mac 베타 (SDR Rec.709, 영상 편집 중심).
> 목적: 실제 사용자가 핵심 작업을 끝낼 수 있는지, 어디서 막히는지, 다시 쓸/지불할 의향이 있는지 측정.
> 권장 인원: **10~20명** (리뷰 §8). 각 테스터가 이 가이드를 따라 한 뒤 §3 메트릭 시트를 기록해 돌려줍니다.

이 가이드는 **사람이 실제 앱 UI를 클릭**하며 따라 하는 체크리스트입니다.
`scripts/run_beta_scenarios.sh`와 다릅니다 — 그 스크립트는 베타 **전** "빌드에서 과제가 기계적으로 통과하는지" 사전 점검하는 것이고, 이 가이드는 **사람의 사용성**을 측정합니다.

---

## 1. 테스터에게 줄 1줄 소개

> MovieCut은 iPhone/카메라로 찍은 영상을 클라우드 업로드 없이, Mac에서 빠르게 편집하고 정확한 색으로 완성하는 로컬 영상 편집기입니다. 다음 6단계를 따라 한 뒤, 몇 가지 질문에 답해 주세요.

## 2. 베타 과제 (6단계)

테스터에게 **도움말 없이** 진행하게 합니다. 각 단계에서 **시간**과 **막힌 지점**을 기록합니다.

- [ ] **1. 영상 가져오기** — 앱을 열고, 영상 파일(또는 2~3개)을 가져옵니다.
- [ ] **2. 첫 컷 만들기** — 타임라인에서 클립을 자르고(trim), 순서를 바꿉니다.
- [ ] **3. 색보정 또는 프리셋 적용** — 한 클립에 색보정(밝기/대비/따뜻함) 또는 색보정 프리셋을 적용합니다.
- [ ] **4. 자막·텍스트 추가** — 텍스트 오버레이를 한 클립 위에 올립니다.
- [ ] **5. 세로형으로 출력** — 9:16(TikTok/Reels/Shorts) 비율로 영상을 내보냅니다.
- [ ] **6. 저장 후 다시 열기** — 프로젝트를 저장하고, 앱을 완전히 끈 뒤 다시 엽니다.

**측정(각 단계):** 완료 시간(초) · 막힌 지점(자유 응답) · 포기 여부

## 4. 주최자(개발자) 체크리스트 — 베타 배포 전

- [ ] `scripts/run_beta_scenarios.sh` 통과 (빌드에서 베타 과제가 기계적으로 완수되는지 사전 점검)
- [ ] `scripts/verify_gate.sh` 통과 (빌드 + 테스트 + 앱 컴파일)
- [ ] 빌드를 테스터에게 전달할 방법 결정 (TestFlight / DMG / 직접 설치)
- [ ] 이 가이드 + 메트릭 시트 템플릿을 테스터에게 배포
- [ ] 회수 기한 설정 (권장: 배포 후 1주)

## 5. 회수 후 분석 기준

- **출시 결정의 핵심 신호**: 6단계 완료율, 첫 export 성공률, "다시 사용할 의향" 평균.
- **차기 우선순위 신호**: "가장 필요하지만 없었던 기능"의 빈도 (상위 3개 → 백로그).
- **회색 신호**: 지불 의향은 가격대와 함께 해석 (단독 지표로 오용 금지).

> 참고: "1031개 테스트 통과"는 내부 정보이지 사용자 체감 지표가 아닙니다(docs/README.md §6 rule #3). 베타 메트릭이 출시 판단의 사용자 측 근거입니다.
