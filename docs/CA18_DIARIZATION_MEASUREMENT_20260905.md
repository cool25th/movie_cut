# CA-18 화자 분리(diarization) 측정 보고 — 명시적 실패 (2026-09-05)

> 백로그 §0.5.1 CA-18 "측정 단계만 승인(2026-08-23)"의 실행 결과. 게이트형 연구의 설계대로
> **미통과를 명시적으로 기록**하며, UI 착수 승인은 요청하지 않는다.

## 사전등록 (측정 전 고정 — 백로그 행 원문)

- T1 화자 혼동율 ≤ 10% (합성·실조건 각각, 음성 지속시간 기준)
- T2 RTF ≤ 0.5 (처리 wall-time / 오디오 길이)
- 측정 후보·임계값 모두 결과를 보고 조정하지 않음(중간에 발견한 측정 품질 결함 2건은 후보 품질이 아닌 하니스 결함이므로 수정 후 재측정: EOF 초과 read throw·VAD 임계치 편향 — 아래 참고)

## 측정 설계

- **후보(연구 코드 — 제품 소스 무편입)**: 에너지 VAD(25ms 프레임·p95의 8% 임계·0.25s 갭 병합) → 세그먼트별 평균 로그스펙트럼(512pt FFT 하위 64빈·최대 8프레임) → 결정론적 2-means(최원거리 쌍 초기화) → 최적 레이블 순열 하 혼동율.
- **픽스처(`scripts/run_ca18_diarization.sh`)**: `say` Yuna(ko_KR)/Daniel(en_GB) 교대 12발화·0.4s 갭(합성축) + 동일 스케줄에 핑크노이즈 ≈12dB SNR(실조건 **대체**축 — 실제 인간 녹음은 사용자 확보 필요, 대체는 보고 조건).
- **측정 실행**: `Tests/MovieCutCoreTests/DiarizationMeasurementTests.swift`(env 게이트·판정 라인 강제).

## 결과 (2회 재현·동일 수치)

| 축 | 검출 세그먼트 | 화자 혼동율 | RTF | 판정 |
|---|---|---|---|---|
| 합성(Yuna/Daniel) | 12/12 | **40.1%** | 0.008 | T1 실패(≤10% 초과) |
| 실조건 대체(+노이즈) | 12/12 | **31.9%** | 0.008 | T1 실패(≤10% 초과) |

RTF는 예산의 1.6%로 여유. **혼동율이 임계값의 3~4배** — 명시적 실패.

## 해석 (다음 후보가 왜 필요한가)

평균 로그스펙트럼은 화자 차(음색·언어)와 **발화 내용 의존 변동을 동일하게 담아** 구분력이 부족 — 합성축(한국어 여성 vs 영어 남성, 사실상 최대 대비)조차 40%면 순수 스펙트럼 클러스터링의 한계는 명확. 유망한 후보 방향: ①화자 임베딩(d-vector/x-vector류 — 온디바이스 학습 모델 필요, 오프라인 원칙 하 Core ML 변환 검토) ②F0(피치) 통계+스펙트럼 결합 특징 ③전환 검출(change detection)+국소 클러스터링. 어느 쪽이든 이번 하니스(VAD·픽스처·혼동율 산식)는 그대로 재사용 가능.

## 하니스 결함 2건 (측정 품질 수리 기록)

1. **EOF 초과 read throw**: `AVAudioFile.read(into:frameCount:)`가 파일 끝을 넘는 요청에서 0프레임 반환 대신 throw(프로브 재현) — 남은 프레임만큼만 요청하는 루프로 수정.
2. **VAD 잡음바닥 편향**: 저백분위 앵커 임계치가 TTS 무음을 음성으로 통과시켜 12발화가 1세그먼트로 병합(**혼동율 0의 거짓 통과** — 빠른 성공 불신으로 포착) — p95 상대 임계(≈-22dB)로 교체 후 12/12 정확 분리·실측 실패 판정 도달.

## 결론

- **T2(RTF) 통과, T1(혼동율) 대폭 미달 → CA-18 측정 = 실패로 종결(게이트 차단 유지)**
- UI 착수 승인 요청 없음. 재측정은 새 후보 특징으로 동일 하니스에서 가능.
- 실녹음(인간) 축은 사용자 확보 전제 — 대체(노이즈 변형) 결과만 보고됨.
