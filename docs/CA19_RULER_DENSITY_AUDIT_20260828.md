# CA-19 잔여 — 타임라인 눈금 밀도 감사(장편 분 단위) 보고 (2026-08-28)

> 근거: 백로그 §0.5.1 CA-19 "잔여: 밀도 감사 보고(장편 분 단위)". 스냅+가이드라인은 완료 상태.
> 대상: Mac `TimelineView` 룰러(`TimelineView.swift:676-705`)·그리드(`:758-780`) — iOS는 룰러
> 스트립 자체가 없어(헤더+레인 구조, CA-19 iOS 완료 기록 참조) 본 감사의 대상 아님.

## 1. 눈금 밀도(충돌) 판정 — ✅ 안전(산술 증명)

눈금 간격 선택(`TimelineView.swift:679`): `pixelsPerSecond ≥ 100 → 1s / ≥ 50 → 5s / 그 외 → 10s`.
줌 범위: `timelineZoom 20...300 px/s`(`EditorViewModel.swift:58-59`, `pixelsPerSecond = timelineZoom`).

라벨은 major 눈금(`Int(time) % 10 == 0`)에만 그려지므로 **최악 밀도 = 최저 줌**에서:

| 줌(px/s) | 눈금 간격 | major(라벨) 간격 | 라벨 폭(최대 "59:59"급) | 판정 |
|---|---|---|---|---|
| 20 (최저) | 10s → 200px | 10s 간격이므로 매 눈금 → **200px** | ~40px | 안전(5배 여유) |
| 50~100 | 5s → 250~500px | 10s → 500~1000px | ~40px | 안전 |
| 100~300 (최고) | 1s → 100~300px | 10s → 1000~3000px | ~40px | 안전(라벨 드문 편) |

라벨 충돌은 `10 × pixelsPerSecond < ~50px`, 즉 **줌 < 5px/s**에서만 발생 가능한데 줌 하한이
20px/s라 도달 불가. 2시간 타임라인(7,200s)도 최저 줌에서 콘텐츠 폭 144,000px·라벨 200px 간격으로
동일 밀도 — Canvas가 가시 영역만 그리므로 렌더 부담도 국소적. **결함 없음.**

## 2. 장편 라벨 가독성 — ⚠ 결함(이번에 수정)

라벨이 초 단위 하드코드(`"\(Int(time))s"`)였음 — 장편에서 "3600s"·"7200s"로 표시돼 분 단위
판독이 불가. CA-27이 전송부(MM:SS:FF)를 정통화했지만 룰러는 미적용이었다.

**수정(본 증분)**: Core `TimecodeParser.rulerLabel(forSeconds:)` — 60초 미만 `"45s"`·분 단위
`"12:05"`(초 0채움)·시 단위 `"2:02:05"`의 3단 적응. 룰러 라벨 1곳(그리드 눈금선은 무라벨) 교체.
프레임 필드는 의도적으로 없음 — 룰러 라벨은 굵은 위치 마커(전송부 MM:SS:FF와 역할 구분).
검증: `TimecodeParserTests` 신규 1건(표값 9종 — 0s/59s/1:00/1:35/10:00/59:59/1:00:00/2:02:05)
포함 12/12 PASS.

## 결론

밀도(충돌)는 전 줌 범위에서 산술적으로 안전 — 결함 0건. 가독성 결함(초 고정 라벨)은 적응
포맷으로 수정+테스트로 고착. CA-19 잔여 소멸 — 항목 완전 종결.
