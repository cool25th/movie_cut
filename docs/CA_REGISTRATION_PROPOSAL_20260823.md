## 2. 범위 명문화 제안 (신규 ID 아님) — 승인 권고

**G-09 Inc3 1순위(freeze·speed ramp·reverse 묶음 배선)에 "사용자 액션 표면(UI)"이 포함되는지 문장으로 고정할 것을 제안.**
현재 판정: export 엔진은 Step 7로 구현됐으나 iOS UI는 전항목 `U=○`(Part 10). PARITY_MATRIX §4 1순위는 "Core 모델 소비 배선"까지만 적혀 있어 UI 표면이 범위인지 모호하다.
→ 제안 문구: "Inc3 각 항목의 DoD에는 preview에서 사용자가 발동 가능한 액션 표면(iOS UI)과 실기기 증거(D)를 포함한다. UI 제외 시 해당 항목은 '배선 완료·U 미노출'로 표기한다."
