## 1. 한 줄 요약

**엔진·검증 기반은 FCP급으로 이미 견고하나, "사용자가 만지는 완성층"(자막 스타일·색 편집 UI·효과 탐색·오디오 팬/믹싱)과 "콘텐츠·자동화층"(템플릿·원클릭 스타일)이 두 벤치마크 공통의 주된 격차다.** 신규 미등록 격차 중 눈에 띄는 것은 ① FCP 12의 대사 검색(트랜스크립트 검색), ② CapCut 원클릭 오토스타일, ③ 애니메이션 스티커, ④ 배치/백그라운드 내보내기 4건이다.

## 2. 현재 기준선 (MovieCut이 보유한 것)

코드 인벤토리 전수 조사 결과(2026-08-16 기준, 게이트 4단계 PASS·테스트 1,143개):

- **편집 코어:** 트림/스플릿/리플/슬립/슬라이드(프로 툴 V/C/Y/U + J/K/L 셔틀), 컴파운드 클립(단일 레벨·내부 편집 포함), 마그네틱 패킹, 7속성 키프레임(보간 5종), 마스크 6종, 그룹핑, 마커(standard/beat), 스냅 엔진, 무제한 undo
- **이펙트/색:** 전환 11종, LUT(.cube 임포트 + 절차적 5종), ASC CDL 3-way 휠 + 컬러 커브 + HSL 밴드(수학 완료, **편집 UI 일부 미노출**), 스코프(히스토그램·웨이브폼), 자동 AWB
- **AI/분석(전부 온디바이스):** 자동 자막(Apple Speech + 워드 타이밍 + 카라오케 플래그), 무음 제거 자동컷, 하이라이트 스코어러, 비트 감지, 인물 배경 제거, 모션 트래킹, 자동 리프레임, TTS, 규칙 기반 NL 어시스턴트
- **오디오:** 5밴드 EQ, 덕킹(램프 실증), 보이스오버 녹음, DSP 노이즈 감소·보컬 분리, 음악/SFX 라이브러리, 오디오 추출
- **출력:** H.264/HEVC/ProRes 422·4444, 4K, 커스텀 비트레이트 1–200Mbps, GIF/스틸컷/오디오 전용, 챕터 메타데이터, 소셜 프리셋 5종(ffprobe 실증), thermal 게이트
- **운영체:** 프록시 4단계 + thermal 레더(자동 강등), 30초 자동저장 + 크래시 복구, 스키마 마이그레이션 v1~v4, `.mctemplate` 프로젝트 패키지, 카드뉴스 스튜디오(게이트됨)

**구조적 강점(양 벤치마크 대비 우위):** preview = export 동일 픽셀 경로(`FlattenedTimelineCache` + 공유 PixelProcessor + 골든 하니스), 네트워크 권한 0의 완전 오프라인, thermal 레더, 무제한 undo, 비트 감지(FCP는 12에서야 추가)와 광학 흐름 슬로모션 보유.

## 5. 역전/우위 영역 (양사 대비 MovieCut 앞선 점)

1. **완전 오프라인·프라이버시:** 네트워크 entitlement 0. 자막·배경제거·트래킹이 전부 온디바이스. CapCut(클라우드 의존·데이터 논란)·FCP(Apple Intelligence 일부 클라우드 경로) 대비 명확한 차별화.
2. **프리뷰=출력 픽셀 패리티:** 단일 스냅샷+공유 프로세서+골든 하니스. "프리뷰와 결과물이 다름"은 두 벤치마크에서 여전히 빈번한 불만(SNS에서 export 시 캡션 누락 등)이다.
3. **비트 감지:** FCP 12(2026-01)에서야 정식 추가된 기능을 이미 실증 보유(W2 직결).
4. **온디바이스 자동 자막 + 워드 타이밍:** FCP의 Transcribe to Captions와 동등 이상의 기반(카라오케 확장 직전).
5. **thermal 레더+프록시 자동 강등:** 노트북/모바일 실용성에서 FCP급 배려.
6. **카드뉴스 스튜디오(G-18~G-22):** 양사에 없는 숏폼 카드뉴스 전용 모드(W5 차별화, 현재 게이트됨).

## 8. 격차 기반 우선순위 상위 10

> 방향 문서 §3의 고정 순서와 충돌하지 않도록 재확인한 결과, **1~5는 기존 1단계 로드맵이 그대로 최적**이다. 6~10에 신규 관점을 반영.

1. **G-01 Inc2+ 자동 자막 스타일·카라오케 렌더링** — CapCut 대비 최대 체감 격차(C1), 엔진 완비로 비용 최소, W1 직결
2. **G-02 Inc5–6 HSL·톤커브 편집 UI** — FCP 대비 색 편집 격차(F1), "엔진 있는데 못 쓰는" 최대 항목
3. **G-03 조정 레이어** — FCP 11.1이 표준화한 워크플로(F2), W4 마스터링 잠금해제
4. **G-25 오디오 믹싱 골격(팬·미터·LUFS·null test)** — 팬 부재는 FCP 대비 명백한 결격(F3)
5. **G-06 키프레임 보간 UI + 베지어 그래프** — 숨겨진 기능 제품화, CapCut 키프레임 UX 대비 열위
6. **[신규] N1 대사 검색·미디어 인덱스** — FCP 12가 연 신규 격차(F6), STT 자산 재활용이라는 비대칭 이점
7. **G-24 손떨림 보정 v1** — 방향 문서가 이미 "효과 확대보다 우선"으로 결정(F5), CapCut·FCP 모두 내장
8. **G-28 효과·템플릿 브라우저 + [신규] N2 원클릭 오토스타일** — CapCut 템플릿/Auto-Style 경험의 오프라인 대응(C2·C3)
9. **G-27 iOS 실기기 검증 인프라 → iosFullEditor 게이트 해제 로드맵** — CapCut의 본진(모바일) 부재가 최대 구조적 격차(C4)
10. **[신규] N5 커스텀 폰트 임포트 + F6 벡터스코프 등 소형 완결 항목** — 낮은 비용로 W5·색 완결 마감
