## 1. 확정 포지셔닝

> **CapCut급 핵심 숏폼 제작 속도 + 선택된 워크플로에서 Final Cut Pro급 렌더링·색·음향 일관성 + 완전 오프라인**

- "CapCut/FCP급 전체 패리티"라는 목표 문구는 **폐기**. 두 벤치마크는 움직이는 목표이며 기능 수 경쟁은 불리하다.
- **90%의 정의를 기능 개수가 아닌 5개 대표 작업의 성공률·소요시간·결과 품질로 측정한다.**

| # | 대표 작업 | 핵심 평가 항목 |
|---|---|---|
| W1 | 60초 세로형 토킹헤드 | 자동 자막, 카라오케 강조, 음성 정리, BGM 덕킹, SNS 출력 |
| W2 | 비트 기반 몽타주 | 음악 분석, 비트 마커, 자동 컷, 속도 램프 |
| W3 | 합성 영상 | 크로마키, 인물 분리, 트래킹, 마스크, 블렌딩 |
| W4 | 5분 멀티트랙 마스터 | 컬러 그레이딩, 조정 레이어, 오디오 믹스, ProRes 출력 |
| W5 | 이미지 카드뉴스 | 이미지 배치, 텍스트 애니메이션, 템플릿, 세로형 출력 |

- **90점 지수 가중치**: 워크플로 완결성 35% / 조작성·작업시간 25% / 출력 품질 25% / 안정성·성능 15%
- 자체 평가 65–72%는 이 지수 체계로 재산정하며, 실측은 사용자 벤치마크(대표 작업 시나리오 스크립트)로만 확정한다.

## 4. 아키텍처 방침

### 4.1 오디오 — `AudioRenderGraphSpec` (프리뷰=출력 보장의 오디오 판)

UI 상태를 AVAudioEngine 노드에 직접 연결하지 않는다. **직렬화 가능한 중간 명세**를 두고 프리뷰·출력 모두 여기서 그래프를 생성한다:

```text
AudioRenderGraphSpec
 ├─ Source / Derived Media(스템 등 ML 결과는 버전 기록된 파생 미디어로 캐시)
 ├─ Clip Strip: 채널 매핑 → 게인/페이드 → 정리(노이즈감소·ML) → EQ → 컴프레서 → 크리에이티브 FX → 팬
 ├─ Track Bus: 서밍 → 사이드체인 덕킹 → 트랙 프로세서 → 페이더 → 미터
 └─ Master Bus: 마스터 EQ → 리미터 → LUFS/true-peak 미터 → 인코더
```

설계 규칙: ① 자동화 값은 샘플 시간/명시적 타임베이스 저장(초 단위 금지) ② 노드 latency 선언·look-ahead 보상 ③ 최종 인코딩 후 AAC 재디코딩으로 loudness·클리핑 사후 검사 ④ 프리셋에 알고리즘 버전 포함(재오픈 재현성) ⑤ 프리뷰↔출력 null test 자동화.

SNS "좋은 소리" 프리셋 출발점(내부 기준, 플랫폼 공식 아님): 마스터 -16~-14 LUFS-I / true peak ≤ -1 dBTP / 장면 내 대사 short-term ±2~3 LU / BGM 대사보다 -8~-16dB.

### 4.2 컬러 — HDR는 "출력 옵션"이 아니라 프로젝트 색관리 전환

필요 모델: `SourceColorDescription`(primaries/transfer/matrix/bit depth/range/메타데이터/사용자 오버라이드) → `ProjectColorSpace`(Rec.709 SDR / Rec.2020 HLG / Rec.2020 PQ) → `DisplayTransform`(EDR 프리뷰 / tone-mapped SDR / reference) → `OutputColorDescription`(코덱/비트심/메타데이터/conform 정책). 1단계에서 **전 소스 색 메타데이터 로깅 + 필터별 8비트 가정 감사**부터 시작한다(누적 방지). CoreImage가 half-float HDR 처리를 지원하므로 HDR 때문한 Metal 재작성은 불필요.

### 4.3 렌더러 — CoreImage 유지, 근거 기반 선택적 Metal

Metal 재검토 트리거(하나가 반복 발생 시): 1080p60 p95 > 12ms(최소 지원 Mac) / 드롭프레임 > 실제 편집시간 5% / 4K 출력 > 1.2× 실시간 지속 초과 / 발열 강등 > 5% / GPU·RSS 예산 초과 / mesh warp 등 CI로 표현 불가 알고리즘 / PoC에서 2배+ 개선. 모든 효과에 `EffectCostProfile`(spatial/temporal, passes, 프레임 의존, 프록시 호환, HDR-safe, 캐시 가능, 예상 메모리) 메타데이터를 둔다.

### 4.4 콘텐츠 — 선언형 팩

`.moviecutpack`(manifest.json + templates/effects/luts/stickers/audio/previews). manifest: 최소 앱 버전, 팩 버전, 효과 그래프, 파라미터, 리소스 크기, 예상 비용, HDR 지원, 라이선스, 마이그레이션 규칙, 해시·서명. 실행 코드 없는 검증 가능한 데이터. 핵심 자산은 앱 번들(오프라인 첫 실행 보장), Apple-hosted 선택 자산은 정책 결정 후(§7).

## 5. 검증 방법론 업그레이드 (VERIFICATION_STANDARD 반영)

1. **외부 정합성 축 추가**: 프리뷰=출력은 일관성일 뿐 정답이 아니다. 수학적 reference frame, 독립 구현 대조, 색변환 표준값, 코덱 디코드 후 비교를 추가.
2. **평균 MAE 보완**: p95/p99/최대 오차, 오류 픽셀 비율, 영역별 MAE, SSIM, 인코딩 품질용 VMAF(그레이딩·스태빌 성공 지표로 오용 금지), 색 패치 ΔE, temporal flicker, 알파 경계 전용 검사.
3. **누적 드리프트 검사**: 분당 PTS, 오디오 샘플 위치, 30/60/120분 종료점, VFR/혼합 fps/혼합 sample rate/램프/리버스/컴파운드/프록시 교체 케이스.
4. **AI 지표 보완**: 평균만이 아닌 하위 5%·실패율, 가림 후 재획득, 장면 전환 초기화, 아티팩트 유형 라벨, confidence·fallback 정확도, 블라인드 선호.
5. **UX 측정 신설**: 기능 발견률, 첫 성공 시간, 오조작 수, undo 사용, VoiceOver·키보드 완결성(완료 기준 포함).
6. **벤치마크 고정**: CapCut·FCP 비교는 분기별 버전 고정 + 비교 범위 선언.
