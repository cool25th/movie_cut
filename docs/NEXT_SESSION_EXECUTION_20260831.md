- 외부 조건이 필요하면 준비된 결과, 정확한 차단 조건, 사용자가 해야 할 최소 행동을 제시한다. 완료 가능한 독립 작업은 먼저 끝낸다. 반복 실패·권한·범위 변경에 관한 적용 가능한 중단 규칙은 지킨다.

1. 실제 수정한 작업 ID·파일·사용자에게 달라진 동작.
