# MovieCut UI 디자인 원칙 (Phase 0.7)

> 작성일: 2026-06-24 / 정체성: **Pro 다크 에디터** (CapCut 클론 아님).
> 결정([로드맵](MOVIECUT_PRO_ROADMAP_20260622.md) §0): "CapCut을 Pro급으로" — CapCut의 **우수한 UX/속도/발견성은 계승**, 그 위에 **Pro 밀도·제어**를 얹는다. **"CapCut 유사도" 지표는 폐기** — 능가가 목표인데 유사도를 재는 것은 모순.

## 1. 측정 가능한 원칙 (지표화)

이전 UI 작업은 "CapCut과 비슷한가(similarity ≥ 0.75)"를 쟀다. 폐기하고 아래 **자체 기준**으로 측정한다:

| 원칙 | 정의 | 목표 |
|---|---|---|
| **반응성(Responsiveness)** | 편집 조작 → 화면 반영 지연 | preview 60fps 유지(측정: 5.5ms/frame 여유 확인), 슬라이더 드래그 즉시 반영 |
| **정보 밀도(Density)** | 한 화면이 노출하는 유효 제어 수 | Pro 패널은 CapCut보다 **높은** 밀도(스코프·수치 동시 노출), 단 시각 무게는 토큰으로 억제 |
| **발견성(Discoverability)** | 기능 도달까지 클릭/탐색 수 | 핵심 편집 ≤ 2클릭, 모든 도구는 카드/레일에 상시 노출(타임라인 툴바에 텍스트로 숨기지 않음) |
| **접근성(Accessibility)** | VoiceOver·키보드·대비 | 모든 컨트롤 label/hint, 단축키 맵 완비, 텍스트 대비 WCAG AA |

검증: XCUITest 플로우 녹화(클릭 수)·preview fps 측정·VoiceOver 감사. 시각 회귀는 골든 스크린샷.

## 2. 디자인 시스템 (기존 `MovieCutTheme` 발전)

- **다크 베이스**: editor `#0F0F10`, panel `#17181A`, raised `#202124`. 깊이는 명도 단계로(보더 남발 금지).
- **단일 액센트**: cyan `#36D7FF` — 선택/playhead/primary action에만. 남용 금지(액센트는 신호).
- **클립 타입 색**: video `#1D3038`, audio `#223329`, text `#3A2B1F`, sticker `#382535` — 채도 낮은 톤으로 타임라인 가독성.
- **타이포 밀도**: `MovieCutTypography` + `MovieCutSpacing.xxSmall` — Pro는 조밀하되 위계 명확(헤더/값/라벨 3단).
- **보더 < 명도**: 카드 구분은 보더가 아니라 배경 명도차로. `border` opacity ≤ 0.34.

## 3. 핵심 화면 사양 (Pro 차별화)

### 3-1. 색 그레이딩 패널 ⭐ (CapCut 최대 격차)
CapCut에 없는 전문 그레이딩. Inspector 우측 또는 하단 도크에:
- **스코프**: 파형(luma)·벡터스코프·히스토그램 실시간(작은 타일 3개, 토글로 확대).
- **휠**: Lift/Gamma/Gain 3색 휠 + 마스터 슬라이더.
- **커브**: RGB/개별 채널 톤커브.
- **기본 보정**: 밝기/대비/채도/**warmth/tint**(2026-06-23 구현, 슬라이더 즉시 반영).
- 레이아웃: 스코프(상단 1/3) · 휠(중단) · 커브/슬라이더(하단). 다크, 수치 상시 노출.

### 3-2. Pro Export 화면 ⭐
CapCut 미제공 출력 제어:
- **포맷**: H.264/H.265/**ProRes 422/4444**/GIF/오디오/스틸.
- **해상도/fps**: 4K·10-bit HDR 토글, 24/30/60fps.
- **비트레이트**: 1~200 Mbps 정밀(현재 구현), VBR/CBR.
- **요약 카드**: 예상 파일크기·코덱·컨테이너를 한눈에. 워터마크 없음·로그인 불필요 명시.

### 3-3. 타임라인 밀도
- **클립 우선**: 썸네일/파형/텍스트 스트립을 클립에 직접 렌더(그리드보다 클립이 주인공).
- **선택 상태**: cyan 0.10 fill + 선명한 stroke, trim 핸들 명확.
- **메인 트랙 구분**: 첫 video 트랙 `Main` 배지(구현됨).
- **자기 정렬**: 매그네틱 패킹, beat/마커 틱 스냅.
