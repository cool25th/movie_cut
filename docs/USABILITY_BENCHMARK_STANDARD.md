# MovieCut 사용성 기준서 (Usability Benchmark Standard)

> 버전: 1.0 / 작성일: 2026-07-14 / 적용 플랫폼: **Mac 먼저** (기준 확정 후 iOS 확장)
> **목적**: "사용자가 쉽게 쓴다"를 관찰·측정 가능한 문장으로 고정한다. 두 축 — ① 영상 편집(벤치마크: CapCut, `CAPCUT_BENCHMARK_STANDARD.md` B-ID와 연동) ② 카드뉴스 제작(벤치마크: **미리캔버스** — CapCut은 카드뉴스 전용 워크플로우가 약함).
> 근거: 2026-07-14 사용자 20문답 (§8 원본 기록). 기능 스펙이 아니라 **판정 기준**이다 — 기능 등재는 gap-audit 세션이 §7 후보를 스펙 G/U-ID로 옮긴다.

---

## 1. 공통 규약

- **페르소나 2종** — 모든 기준은 어느 페르소나 기준인지 명시한다.
  - **P-신규**: 영상 편집 앱 첫 실행. 튜토리얼·안내 문서 없이 진행.
  - **P-반복**: CapCut/미리캔버스 경험자. 단축키·패턴 숙지 상태.
- **판정**: 각 기준은 목표값 충족 여부로 ✅/❌. 시나리오(§2)는 완주 시간 + **막힘 0회**가 동시 충족되어야 ✅.
  - **막힘 정의**: 15초 이상 다음 행동을 못 찾음, 또는 같은 목적으로 잘못된 메뉴/버튼을 3회 이상 클릭.
- **검증 방법** (문답 17): 정의된 시나리오를 실제로 완주(화면 녹화 + 타임스탬프)하고, 클릭 수·지연은 자동 측정(DEBUG 하니스 클릭 카운터 / os_signpost)한다. 코드 존재·static contract는 증거 불인정 (기존 검증 규율 준수).
- **미리캔버스 항목의 비교 판정**은 CapCut 벤치마크와 같은 규약: [추정] 상태로 ⬇/❌ 판정 금지, 웹/실사용 확인 후 출처 병기.

## 6. 검증 세션 규약

1. 판정은 §2 시나리오 단위로 한다. 세션 산출물: 녹화 파일 경로 + 구간 타임스탬프 + 클릭 카운트 로그 + ✅/❌ 표.
2. 자동 측정 가능한 것(클릭 수·지연·export 결과물 규격)은 DEBUG 하니스/E2E로 상설화한다 — 예: PNG 세트 export 스모크(장수·해상도·파일명), 영상화 스모크(duration·전환 유무).
3. P-신규 판정은 본인이 하되 "처음 보는 사람처럼" 완주가 어려우므로, UB-V1/UB-C1 최종 확정 전 1회는 실제 초보 1인 관찰을 권장(선택).
4. 이 문서의 목표값 변경은 버전 bump + 변경 이력 1줄.

## 7. 기준 충족을 위한 기능 요구사항 도출 (스펙 미등재 — gap-audit 등재 후보)

현재 코드에 카드뉴스 **워크플로우가 부재**하므로(빌딩블록은 존재: 이미지 클립 G-15, 텍스트 템플릿 14종, CanvasPreset custom, 정지 프레임 PNG·GIF export 경로), UB-C 충족에는 아래 신설이 필요하다. 우선순위는 사용자 답변(동등 가중, 5분 목표, 일괄·브랜드 킷 필수) 기준.

| 후보 | 내용 | 충족 대상 | 재사용 블록 |
|---|---|---|---|
| G-18 카드 문서 모델+편집기 | 페이지(카드) 시퀀스 모델, 카드 추가/복제/순서, 캔버스 인라인 텍스트 편집 | UB-C1/C3/C4 | CanvasPreset, 텍스트 클립 렌더러 |
| G-19 카드 템플릿+마스터 스타일 | 세트 템플릿 10종, 마스터 스타일 1회 변경→전 카드 반영 | UB-C2/C5 | 타이틀 템플릿 14종 파이프라인 |
| G-20 브랜드 킷 | 로고/색/폰트 저장소, 프로젝트 간 재사용 | UB-C6 | — (신규, 비영속 아님) |
| G-21 카드 export | PNG/JPG 세트 일괄 export + 원클릭 9:16 영상화(카드→이미지 클립 시퀀스+전환+BGM 슬롯) | UB-C7/C8, SC-C3 | ExportPlanner still-frame, G-15 이미지 파이프라인, 전환 |
| G-22 대본 자동 분배 | 텍스트 붙여넣기→문단 분배, 온디바이스 요약(요약·분배만, 문안 생성 제외) | UB-C9, SC-C4 | — (차별화, 후순위) |
| U-10 카드뉴스 진입점 | 홈/신규 프로젝트에서 "카드뉴스 만들기" 분기 | SC-C1 첫 단계 | U-01 홈 화면과 묶음 |
| (영상) 클릭 카운터 하니스 | UB-V3/§5 자동 측정 인프라 | UB-V3 | U-08 캡처 하니스 |

권장 착수 순서: **G-18 → G-19(핵심 5분 경로) → G-21(출력 완성) → G-20 → U-10 → G-22**. 단, 진행 중인 편집 체감 P0(G-17 복사/붙여넣기)와 G-04를 먼저 소진할지 여부는 사용자 결정 필요.
