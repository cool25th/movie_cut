## 0. 한 줄 요약

**기능**은 G-플랜(G-01~G-14)이 유효하고 S0가 일부 진행됐다(iOS 빌드 복구 ✅). **UI**는 2026-06-19 IA 패스 + P0/P1/P2 폴리시로 구조(존 배치·탭 브라우저·맥락형 인스펙터)는 CapCut급에 도달했으나, ① **에디터 진입 전 표면이 통째로 없고**(홈/프로젝트 매니저), ② **타임라인 클립 표면의 정보 리치니스**(전환 pill·효과 뱃지·필름스트립)가 부족하며, ③ **제품 완성도 표면**(현지화·환경설정·토스트 피드백·시각 회귀 인프라)이 비어 있다. 이번 V7은 UI 격차를 U-01~U-09로 스펙화해 기능 G-ID와 같은 파이프라인(`/surpass`)에서 실행 가능하게 한다.

## 4. 통합 개선 방향성 — 기능×UI 교차 지점

기능(G)과 UI(U)는 별개 트랙이 아니라 **서로를 요구한다**. 교차 지점을 명시해 세션이 함께 처리하게 한다:

| 기능 G-ID | 요구하는 UI 표면 | 담당 |
|---|---|---|
| G-01 워드 자막 | 캡션 스타일 갤러리(카드+미니 프리뷰) | G-01 Inc 5에 내장 |
| G-02 HSL/커브 | 커브 에디터·HSL 탭 — 그레이딩 패널 재편 | G-02 Inc 5/6에 내장 |
| G-03 조정 레이어 | 타임라인 전용 클립 렌더 + 인스펙터 필터링 | G-03 Inc 4/5에 내장 |
| G-04 필름스트립 | 클립 표면 렌더 — **U-02(클립 뱃지·전환 pill)와 같은 코드 영역** → 같은 세션 묶음 권장 |
| G-07 이펙트 팩 | 브라우저 그리드 — **U-07(브라우저 리듬 통일)과 병합 실행** |
| G-08 에셋 팩 | 음악/SFX 브라우저 미리듣기 — U-07 리듬 적용 |
| G-11 export 큐 | 큐 패널 UI + U-04 토스트(잡 완료 알림) 의존 |
| G-09 iOS | U-ID 전부의 iOS 대응 판단 포함 |

**방향성 4줄 요약**:
1. **에디터 밖 표면 신설** — 홈/프로젝트 매니저(U-01)와 환경설정(U-05)으로 "앱"이 아니라 "제품"으로.
2. **타임라인을 정보 표면으로** — 전환 pill·뱃지·필름스트립(U-02+G-04)로 "적용된 것이 보이는" 타임라인.
3. **제품 완성도 기반** — 현지화(U-06)·토스트(U-04)·UI 회귀 인프라(U-08)는 모든 후속 UI 작업의 지반.
4. **Pro UI로 능가** — 커맨드 팔레트(U-09)·스코프 도크(G-02 내장)는 CapCut이 못 따라오는 표면.

## 6. 권장 실행 순서 (기능 S-트랙과 병행 슬롯)

> UI 트랙은 로드맵 관례대로 **전 단계 병행**. 기능 세션 사이에 UI 세션을 끼워 넣는 슬롯 방식.

| 슬롯 | 기능 트랙 | UI 트랙 |
|---|---|---|
| 1 | S0 마감: G-12 부채(오디오·플랫폼 묶음) + G-09 CI job | **U-08 인프라 선행**(이후 UI 작업의 증거 기반) |
| 2 | S1: G-02 HSL/커브 (UI 포함) | U-02 + G-04 묶음(타임라인 표면) |
| 3 | S1: G-03 조정 레이어 | U-01 홈 화면 |
| 4 | S2: G-01 워드 자막 (UI 포함) | U-04 토스트 → U-03 트랙 → U-05 설정 |
| 5 | S3: G-05/G-06 | U-06 현지화 |
| 6 | S4: G-07/G-08 | U-07 병합 실행 → U-09 팔레트 |

각 UI 세션 DoD는 스펙 §5 공통 규칙(레이아웃 계약 테스트 + U-08 캡처 증거 + `docs/UI_DESIGN_PRINCIPLES.md` 지표) 준수.
